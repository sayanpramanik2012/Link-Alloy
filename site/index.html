INDEPENDENT WINDOWS IMPLEMENTATION · DEVELOPMENT PREVIEW

More links, one clear control.

Link Alloy is being developed for people who connect a Windows PC to more than one independent internet link. The current preview discovers adapters; it does not route traffic or claim a speed boost.

Routing engine in development · no installer released

What the current preview does

The starter app is intentionally read-only. It shows network interface names, type, operating-system link state, index, and MTU. It does not change proxies, routes, adapters, or traffic.

01 / DISCOVER

List available adapters

See Ethernet, Wi-Fi, tethered devices, and other non-loopback interfaces reported by Windows.

02 / DESIGN

Develop a new engine

The connection scheduler, traffic capture, and adapter telemetry are being implemented in this new codebase.

03 / VALIDATE

Test before release

The routing feature will not be advertised as usable until local tests verify traffic distribution and cleanup behavior.

Approach and inspiration

Multi-link networking is an established category. Link Alloy is a separate implementation informed by publicly described behavior; this repository contains no source files from these products and is not affiliated with them.

LOCAL CONNECTION SCHEDULING

Link Alloy’s planned model

Assign each new connection to one selected adapter. Existing TCP sessions may reconnect if their public route changes; no zero-interruption claim is made.

OTHER PUBLISHED DESIGNS

Different trade-offs

HypoMux and HypoMuxPlus document connection-level approaches. Speedify describes packet-level distribution with server-side reassembly.
