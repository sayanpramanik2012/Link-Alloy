INDEPENDENT WINDOWS MULTI-LINK NETWORKING

More links, one clear control.

Link Alloy is a general-purpose Windows networking app designed to route supported system traffic across Ethernet, Wi-Fi, USB tethering, and other active links. It does not require launcher-specific setup.

What Link Alloy is building

The desktop control panel is connected to a new Go routing engine. A short elevated smoke verified Wintun startup, Windows route selection, eight HTTPS flows across two egress paths, and route restoration. A sustained application download and link-loss failover still need validation.

01 / SELECT

Route new connections

Link Alloy assigns each supported TCP or UDP flow to one healthy network adapter.

02 / OBSERVE

See traffic by link

Review per-link health, live upload/download rates, byte totals, active flows, and recent engine events.

03 / RECOVER

Restore Windows routes

A cleanup journal tracks the temporary routes so Link Alloy can restore them when stopped or recover after a restart.

Independent implementation

Link Alloy's scheduler, packet mapping, Windows route lifecycle, and interface selection are authored in this repository. The app uses the gVisor TCP/IP stack and Wintun's public driver API as third-party components under separate licenses. No application source files from other multi-link products are included.

LOCAL CONNECTION SCHEDULING

One path per new flow

Assign each new connection to one selected adapter. One TCP connection is not split across links. Existing sessions may reconnect after a route or public-IP change.

OTHER PUBLISHED DESIGNS

Different trade-offs

HypoMux and HypoMuxPlus document connection-level approaches. Speedify describes packet-level distribution with server-side reassembly.
