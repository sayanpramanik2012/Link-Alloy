A practical control plane for multi-link PCs.

Link Alloy is built for a PC that has more than one usable path to the internet. It gives new connections a healthy egress link, makes the decision visible, and restores the routes it owns when the session ends.

01 / ROUTE

Choose eligible links

Enable or exclude Ethernet, Wi-Fi, mobile tethering, and other supported adapters from Settings.

02 / OBSERVE

See the real traffic

Review per-link health, active connections, fixed-window rates, totals, diagnostics, and local events.

03 / RECOVER

Keep Windows safe

Protected state, ownership locking, bounded cleanup, and recovery handling keep temporary routes explainable.

Own engine. Clear boundaries.

The Link Alloy scheduler, flow mapping, adapter-bound dialing, Windows route lifecycle, health orchestration, logging, and frontend are authored in this repository. gVisor and Wintun remain separately licensed third-party components.

Connection scheduler

New flows are assigned with configured weighted round-robin across healthy adapters. Existing flows remain pinned to their selected link.

new flow → health check → weighted egress → fixed upstream link

Windows tunnel lifecycle

The elevated engine owns Wintun, split routes, protected journals, single-instance locking, and bounded recovery.

start → validate → install → observe → restore

PRE-RELEASE

Clear answers before you run it.

The product is explicit about what it does so measurements are useful and troubleshooting stays straightforward.

Will one EA or Steam connection use both links?

No. Link Alloy schedules separate connections. A launcher with enough parallel connections can use both links; one existing TCP connection remains on one link.

Should I reopen the launcher?

Yes when the launcher was already downloading before the tunnel started. Restarting or pausing/resuming creates fresh connections that the scheduler can assign.

What happens if Wi-Fi drops?

Repeated failed health checks remove Wi-Fi from new-flow selection. Existing Wi-Fi connections may need to reconnect after the public route changes.

What should I do when I stop?

Stop the tunnel in Link Alloy first, wait for the status to settle, then close the application. This lets the engine restore the routes it owns.
